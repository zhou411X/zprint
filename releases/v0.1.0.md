# zprint v0.1.0

zprint 是面向 Ubuntu 24.04 GNOME / Wayland 的原生截图标记工具。

## 主要功能

- 通过系统截图界面捕获区域、窗口或全屏，自动加载到编辑器。
- 支持从剪贴板读取图片；新图片直接替换当前图片和标记，无需确认保存。
- 箭头、画笔、中文多行文本、矩形、圆形、马赛克和连续数字标记。
- 自定义颜色，使用滑块调整线宽、打码强度和字号。
- 撤销重做、移动删除、图片缩放、PNG/JPEG 导出及复制到剪贴板。
- 在设置中配置全局快捷键、查看操作帮助和版本号。

## 安装

下载本页的 `zprint_0.1.0-1_all.deb`，在下载目录执行：

```sh
sudo apt install ./zprint_0.1.0-1_all.deb
```

安装后从应用菜单打开 **zprint**，或执行 `/usr/bin/zprint`。默认全局快捷键会在当前用户首次启动时注册：

- `Ctrl+Alt+S`：系统截图并打开编辑器。
- `Ctrl+Alt+V`：打开剪贴板图片。

如快捷键已被占用，请进入“设置 → 快捷键设置”调整。DEB 安装过程不修改 root 或其他用户的桌面配置。系统安装包的版本为 `0.1.0-1`，应用显示 `0.1.0`。

如果此前使用源码的 `install.sh` 安装过，请先关闭 zprint，在源码目录执行 `sh install.sh --uninstall`，再安装 DEB，避免旧的用户桌面入口和启动命令优先于系统安装。源码和导出的图片会保留；旧用户安装对应的快捷键需在新版中重新设置。

校验附件：`sha256sum -c SHA256SUMS`。卸载系统包：`sudo apt remove zprint`。

## 已知限制

- 主要目标环境为 Ubuntu 24.04 GNOME 46 / Wayland；其他桌面的截图和快捷键行为未验证。
- 首次截图可能出现系统权限确认；真实截图选区及自定义全局快捷键需要桌面交互验证。
- 新图片会清空旧图片的标记和撤销历史；导出为合成图片，不包含可恢复图层。
- 应用退出后，剪贴板图片能否保留取决于桌面剪贴板管理器。
