# zprint v0.2.0

面向 Ubuntu 24.04 / GNOME 46 / Wayland 的截图标记更新：拖选截图，松开鼠标即可在桌面原选区标记。

## 新功能与修复

- 新增 GNOME 46 扩展。使用 zprint 截图快捷键（默认 `Ctrl+Alt+S`）冻结桌面并拖选，松开后直接显示浮动工具栏；支持反向拖选、Esc / 右键取消，单击不生成截图。
- 在原选区绘制箭头、画笔、文字、形状、马赛克和数字；支持颜色、粗细、字号、撤销重做及导出。工具栏会根据屏幕边缘调整位置。
- `✓` / Enter 复制并收起，`×` / Esc 放弃并收起，`↗` 转入完整编辑器并保留标记和撤销历史。工具栏和选区边框不会进入导出图片。
- 修复 portal 与扩展通知顺序不同导致的错误提示遮挡输入或重复打开图片。连续截图清空旧图片、标记和历史；自定义截图缓存会在收起或下一次自定义截图时清理。
- 系统 PrintScreen 仍打开 GNOME 截图界面；启用扩展后，系统截图完成也可进入浮动标记。扩展不可用时，zprint 截图入口回退到系统 portal。
- DEB 包包含扩展，源码安装支持 `sh install.sh --enable-shell-extension`。普通剪贴板图片和文件仍使用完整编辑器。

## 安装与升级

下载本页的 DEB 和 `SHA256SUMS`，在下载目录执行：

```sh
sha256sum -c SHA256SUMS
sudo apt install ./zprint_0.2.0-1_all.deb
```

应用版本为 `0.2.0`，Debian 包版本为 `0.2.0-1`。从旧版 DEB 升级使用同一命令；先退出旧进程，升级后重新启动。已有快捷键设置保留，默认剪贴板入口为 `Ctrl+Alt+V`。

如曾用源码 `install.sh` 安装，请先关闭 zprint，在源码目录执行 `sh install.sh --uninstall`，再安装 DEB，避免旧的用户应用或扩展遮盖系统版本。源码和导出图片保留；该卸载操作移除的快捷键需在新版中重新设置。

首次安装或更新扩展后，保存桌面工作，**注销并重新登录**，再以当前桌面用户执行：

```sh
gsettings set org.gnome.shell disable-user-extensions false
gnome-extensions enable zprint@zhou411X
gnome-extensions info zprint@zhou411X
/usr/bin/zprint
```

DEB 安装不会自动启用扩展、注销桌面或修改 root 的快捷键。扩展仅支持 GNOME 46；无需浮动模式时执行 `gnome-extensions disable zprint@zhou411X`。

## 验证

- `make build` 通过。
- `make test`：63 项 Python 测试、5 项 JavaScript 工具栏布局检查通过，0 失败。
- `make test-shell`：17 项隔离 GNOME 46 / Wayland 场景通过，覆盖区域、窗口、全屏截图、浮动定位、鼠标标记、撤销重做、通知竞态、取消恢复、连续截图及扩展停用。

## 已知限制

- 物理多显示器、分数缩放、真实全局快捷键及 portal 权限弹窗仍需实际桌面验证。
- 新截图替换旧图片和标记；请先复制或导出需要保留的结果。关闭应用后，剪贴板保留情况取决于桌面剪贴板管理器。
- 扩展依赖 GNOME 46 接口，其他 GNOME 版本及桌面环境未验证。
- 未在全新 Ubuntu 系统执行实际的 apt 安装；自动化会检查包内容、依赖模拟及解包后的应用。
